01

這是什麼

Hermes Agent 是一個在終端機裡跟你對話、可以幫你執行任務的 AI agent。 公司把它裝在內部共用位置，你只要在自己的帳號下跑一次安裝腳本， 之後打 hermes 就能開始使用——設定檔、對話紀錄、API 金鑰 全部留在你自己的家目錄，不會跟其他同仁互相影響。

  • 不需要 root / sudo 權限
  • 不需要對外網路，安裝與更新都在公司內網完成
  • 個人資料（API 金鑰、對話紀錄、技能）只存在你自己的帳號下
02

安裝：一行指令

找系統管理員拿到共用目錄的實際路徑（下面以 /mnt/shared/hermes-agent 為例），在你自己的帳號下執行：

your-account@centos7
$ bash /mnt/shared/hermes-agent/client/hermes-agent-setup.sh ⚕ hermes-agent 個人安裝 共用執行環境: /mnt/shared/hermes-agent ✓ 目前共用版本: 0.15.1 ✓ 已建立 ~/.local/bin/hermes ✓ 已將 ~/.local/bin 加入 PATH ✓ 個人設定目錄: ~/.hermes ✓ 安裝完成！ 要現在執行設定精靈 (hermes setup) 嗎？ [Y/n]
NOTE

腳本只會動到你自己的帳號：建立 ~/.local/bin/hermes 這個指令， 以及 ~/.hermes 這個個人設定目錄。共用目錄本身是唯讀的， 你不會、也不需要去動到它。

裝完之後重新載入 shell 設定（或重新登入一次），指令就能直接使用：

$ source ~/.bashrc
03

第一次設定

安裝腳本最後會問你要不要直接跑設定精靈；如果當下跳過了，之後隨時可以自己執行：

$ hermes setup

設定精靈會引導你填入 API 金鑰、選擇預設模型等個人設定。這些內容只會寫進 ~/.hermes/config.yaml 和 ~/.hermes/.env，只有你自己看得到。

04

日常使用

常用指令：

hermes開始跟 Hermes 對話
hermes setup重新設定 API 金鑰、預設模型
hermes status查看目前的設定狀態
hermes doctor健康檢查，診斷安裝或設定問題
hermes --help列出所有可用指令
05

版本更新怎麼運作

你不需要做任何事。Hermes Agent 的執行環境是共用的， 管理員發佈新版時只是把「目前版本」指到新的位置， 你下一次執行 hermes 指令，就自動是新版本。

舊版本
0.15.0
→
管理員發佈後・目前版本
0.15.1
你這邊什麼都不用做，下次打 hermes 就是新版本
好處

如果你更新當下正好在跟 Hermes 對話，也不會被中斷——正在跑的對話 會繼續用它啟動當下的版本，跑完之後下次啟動才會換新版。

想確認自己目前用的是哪個版本，兩種方式都可以：

$ hermes --version Hermes Agent v0.15.1
06

疑難排解

command not found重新登入，或執行 source ~/.bashrc
hermes doctor 有 ✗照畫面上的說明處理；解不掉再找管理員
忘記填 API 金鑰重新執行 hermes setup

如果要移除自己安裝的部分：

$ bash /mnt/shared/hermes-agent/client/hermes-agent-uninstall.sh ✓ 已移除 ~/.local/bin/hermes ! 個人設定目錄 ~/.hermes 未刪除（保留 API 金鑰與對話紀錄） $ 加上 --purge 才會連個人資料一起永久刪除： $ bash /mnt/shared/hermes-agent/client/hermes-agent-uninstall.sh --purge
